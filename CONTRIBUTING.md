# Руководство по вкладу в проект METALINE

Спасибо за интерес к проекту METALINE! Мы приветствуем вклад от сообщества.

## Как начать

1. **Форкните репозиторий**
   - Нажмите кнопку "Fork" в правом верхнем углу

2. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/your-username/metaline-website.git
   cd metaline-website
   ```

3. **Установите зависимости**
   ```bash
   npm install
   # или
   ./setup.sh install
   # или
   make install
   ```

4. **Создайте ветку для вашей фичи**
   ```bash
   git checkout -b feature/amazing-feature
   ```

5. **Запустите dev-сервер**
   ```bash
   npm run dev
   # или
   ./setup.sh dev
   # или
   make dev
   ```

## Процесс разработки

### Стиль кода

- Используйте **TypeScript** для всех новых файлов
- Следуйте существующему стилю кода
- Используйте **Tailwind CSS** для стилизации
- Пишите осмысленные имена переменных и функций на английском
- Комментарии пишите на русском языке

### Структура компонентов

```typescript
// Пример структуры компонента
export default function ComponentName() {
  // 1. Хуки и состояния
  const [state, setState] = useState();
  
  // 2. Эффекты
  useEffect(() => {
    // ...
  }, []);
  
  // 3. Обработчики
  const handleClick = () => {
    // ...
  };
  
  // 4. Рендер
  return (
    <div>
      {/* JSX */}
    </div>
  );
}
```

### Коммиты

Используйте семантические сообщения коммитов:

```
feat: добавлена новая секция портфолио
fix: исправлена ошибка навигации на мобильных
style: обновлены цвета кнопок
docs: обновлена документация
refactor: оптимизация рендеринга
test: добавлены тесты для компонента
chore: обновление зависимостей
```

### Pull Request

1. **Убедитесь, что код работает**
   ```bash
   npm run build
   ```

2. **Обновите документацию** (если необходимо)

3. **Создайте Pull Request**
   - Опишите изменения подробно
   - Добавьте скриншоты (если это UI изменения)
   - Укажите связанные issues

## Типы вклада

### 🐛 Исправление багов

- Опишите баг в issue
- Приложите скриншоты
- Укажите шаги для воспроизведения

### ✨ Новая функциональность

- Обсудите идею в issue перед реализацией
- Предоставьте детальное описание
- Создайте PR с реализацией

### 📝 Документация

- Исправление опечаток
- Улучшение существующей документации
- Добавление примеров

### 🎨 Дизайн

- Улучшение UI/UX
- Оптимизация для мобильных устройств
- Доступность (a11y)

### ⚡ Производительность

- Оптимизация загрузки
- Уменьшение размера бандла
- Улучшение скорости рендеринга

## Проверка перед PR

Перед созданием Pull Request убедитесь:

- [ ] Код собирается без ошибок: `npm run build`
- [ ] Нет ошибок в консоли браузера
- [ ] Адаптивность работает на всех размерах экрана
- [ ] Все ссылки и навигация работают
- [ ] Изображения загружаются корректно
- [ ] Код соответствует стилю проекта

## Вопросы?

Если у вас есть вопросы:
- Создайте issue с меткой `question`
- Напишите на info@metaline.ru

Внося вклад в проект, вы соглашаетесь с тем, что ваш код будет лицензирован под теми же условиями, что и основной проект.
