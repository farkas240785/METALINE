# Загрузка изображений в админ-панели

## 📸 Возможности

### Загрузка с компьютера
- **Drag & Drop** — перетащите файл в зону загрузки
- **Выбор файла** — нажмите на зону для выбора через диалог
- **Мгновенное превью** — изображение отображается сразу после загрузки
- **Автоматическое сохранение** — все загруженные изображения сохраняются в галерее

### Галерея изображений
- **Загруженные изображения** — ваши файлы отображаются первыми
- **Предустановленные** — стандартные изображения из системы
- **Повторное использование** — выберите любое изображение из галереи
- **Удаление** — удалите ненужные изображения (крестик при наведении)

## ⚙️ Технические ограничения

### Форматы файлов
- ✅ PNG
- ✅ JPG / JPEG
- ✅ WEBP
- ✅ GIF

### Размер файлов
- **Максимум**: 2 МБ на изображение
- **Рекомендация**: оптимизируйте изображения перед загрузкой
- **Формат хранения**: base64 в localStorage

### Лимиты хранилища
- **Галерея**: до 20 загруженных изображений
- **localStorage**: ~5-10 МБ (зависит от браузера)
- **Общий размер**: учитывайте все данные сайта

## 🎯 Как использовать

### Загрузка нового изображения

1. Откройте форму редактирования (продукт или проект)
2. Найдите поле "Изображение"
3. **Вариант 1: Drag & Drop**
   - Перетащите файл из проводника в зону загрузки
   - Дождитесь появления превью
4. **Вариант 2: Выбор файла**
   - Нажмите на зону загрузки
   - Выберите файл в диалоге
   - Подтвердите выбор
5. Изображение автоматически сохранится в галерею

### Выбор из галереи

1. В форме редактирования прокрутите до раздела "Галерея"
2. **Загруженные изображения** — ваши файлы (отображаются первыми)
3. **Предустановленные** — стандартные изображения
4. Нажмите на нужное изображение
5. Оно автоматически подставится в поле

### Удаление изображения из галереи

1. Наведите курсор на изображение в галерее
2. Появится крестик в правом верхнем углу
3. Нажмите на крестик
4. Изображение удалится из галереи
5. Если оно используется в продукте/проекте, поле очистится

## 💡 Рекомендации

### Оптимизация изображений

**Перед загрузкой:**
- Сожмите изображение (TinyPNG, Squoosh)
- Измените размер до нужного (1920x1080 для проектов, 800x800 для продуктов)
- Используйте формат WEBP для лучшего сжатия

**Инструменты:**
- [TinyPNG](https://tinypng.com/) — онлайн-сжатие
- [Squoosh](https://squoosh.app/) — конвертация и оптимизация
- [ImageOptim](https://imageoptim.com/) — для macOS
- [FileOptimizer](https://nikkhokkho.sourceforge.io/) — для Windows

### Когда использовать внешние хостинги

Используйте внешние хостинги, если:
- Изображения больше 2 МБ
- Нужно более 20 загруженных файлов
- Требуется CDN для быстрой загрузки
- Необходима версионность изображений

**Популярные хостинги:**
- [Imgur](https://imgur.com/) — бесплатный, простой
- [Cloudinary](https://cloudinary.com/) — профессиональный, с API
- [ImageKit](https://imagekit.io/) — с оптимизацией
- [Uploadcare](https://uploadcare.com/) — с виджетом загрузки

### Управление localStorage

**Проверка занятого места:**
```javascript
// В консоли браузера
let total = 0;
for (let key in localStorage) {
  if (localStorage.hasOwnProperty(key)) {
    total += localStorage[key].length + key.length;
  }
}
console.log(`Занято: ${(total / 1024 / 1024).toFixed(2)} МБ`);
```

**Очистка загруженных изображений:**
```javascript
// Удалить все загруженные изображения
localStorage.removeItem('metaline_uploaded_images');
location.reload();
```

## 🐛 Устранение неполадок

### "Размер изображения не должен превышать 2 МБ"
- Сожмите изображение перед загрузкой
- Измените размер изображения
- Используйте формат WEBP

### "localStorage переполнен"
- Удалите старые загруженные изображения из галереи
- Удалите ненужные продукты или проекты
- Очистите localStorage полностью

### Изображение не отображается
- Проверьте, не удалено ли оно из галереи
- Обновите страницу (F5)
- Проверьте консоль браузера на ошибки

### Изображение загружается долго
- Оптимизируйте размер файла
- Проверьте интернет-соединение
- Используйте более легкий формат (WEBP)

## 📊 Сравнение с внешними хостингами

| Характеристика | localStorage | Внешний хостинг |
|----------------|--------------|-----------------|
| Скорость загрузки | Быстро (локально) | Зависит от CDN |
| Лимит размера | 2 МБ | Без ограничений |
| Количество файлов | 20 | Без ограничений |
| Стоимость | Бесплатно | Часто платно |
| Надежность | Зависит от браузера | Высокая |
| CDN | Нет | Да |
| Оптимизация | Нет | Да |

## 🔒 Безопасность

- Изображения хранятся в base64 формате
- Данные привязаны к браузеру пользователя
- Нет передачи на внешние серверы
- Полная конфиденциальность
