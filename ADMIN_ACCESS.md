# Инструкция по доступу к админ-панели METALINE

## 🔐 Вход в админ-панель

### Способ доступа:
1. Откройте сайт в браузере
2. Добавьте `#/admin` в конце URL
3. Введите пароль: **admin**
4. Нажмите "Войти"

### Пример URL:
```
https://metaline.tech/#/admin
```

## 📋 Возможности админ-панели

### 1. Дашборд
- Статистика заявок и проектов
- Графики активности
- Последние действия

### 2. Управление продукцией
- Добавление/редактирование/удаление продуктов
- Загрузка изображений
- Управление ценами и характеристиками

### 3. Портфолио
- Управление проектами
- Загрузка фотографий
- Публикация/скрытие проектов

### 4. Заявки
- Просмотр всех заявок
- Изменение статусов
- Приоритеты и фильтрация

### 5. Техническая библиотека
- Управление документами
- Категоризация
- Отслеживание скачиваний

### 6. Пользователи
- Управление доступом
- Роли и права

### 7. Настройки
- Контактная информация
- Социальные сети
- SEO настройки

## 🚪 Выход из админки

- Нажмите кнопку "Выйти" в боковой панели
- Или нажмите "Открыть сайт" для возврата

## ⚠️ Важно

- Пароль хранится только в коде (демо-версия)
- Для production необходимо настроить серверную аутентификацию
- Данные сохраняются в localStorage браузера

## 🛠 Разработка

Для изменения пароля откройте файл:
```
src/admin/LoginPage.tsx
```

Найдите строку:
```typescript
if (password === 'admin') {
```

И замените `'admin'` на свой пароль.
