# Административная панель METALINE

Полнофункциональная админ-панель для управления контентом сайта METALINE.

## 🚀 Доступ к админ-панели

### URL доступа
Добавьте `#/admin` к URL сайта:
```
https://your-domain.com/#/admin
```

### Аутентификация
- **Пароль:** `admin`
- Введите пароль на странице входа
- После успешной аутентификации вы попадёте в админ-панель

### Выход из админки
- Нажмите кнопку **"Выйти"** в боковой панели
- Или нажмите **"Открыть сайт"** для возврата на основной сайт
- Сессия завершится и потребуется повторный ввод пароля

## 📊 Разделы админ-панели

- Статусы проектов
- Последние заявки
- Быстрые действия

- Изменение статуса (активен/скрыт)
- **Загрузка изображений с компьютера** (drag & drop или выбор файла)
- Выбор из галереи загруженных или предустановленных изображений
- Управление ценами и рейтингами
- Поиск по названию

### 3. Портфолио
Управление проектами:
- Добавление новых проектов
- Редактирование существующих
- Фильтрация по статусу (опубликовано/черновик)
- **Загрузка изображений с компьютера** (drag & drop или выбор файла)
- Выбор из галереи загруженных или предустановленных изображений
- Управление рейтингами

### 4. Заявки
Обработка входящих заявок:
- Просмотр всех заявок
- Фильтрация по статусу
- Изменение статуса заявки
- Просмотр деталей заявки
- Управление приоритетами

### 5. Техническая библиотека
Управление документами:
- Добавление новых документов
- Редактирование информации
- Удаление документов
- Отслеживание скачиваний
- Категоризация документов

### 6. Пользователи
Управление доступом:
- Просмотр списка пользователей
- Блокировка/активация пользователей
- Просмотр ролей и последнего входа

### 7. Настройки
Конфигурация сайта:
- **Общие**: название компании, режим обслуживания
- **Контакты**: телефоны, email, адрес, часы работы

- **SEO**: мета-теги для поисковых систем

## 📸 Загрузка изображений

### Возможности:
- **Drag & Drop** — перетащите файл в зону загрузки
- **Выбор файла** — нажмите на зону загрузки для выбора файла
- **Превью** — мгновенный предпросмотр загруженного изображения
- **Галерея** — все загруженные изображения сохраняются и доступны для повторного использования
- **Удаление** — возможность удалить загруженные изображения из галереи

### Ограничения:
- **Форматы**: PNG, JPG, JPEG, WEBP, GIF
- **Максимальный размер**: 2 МБ на изображение
- **Лимит галереи**: 20 загруженных изображений
- **Хранение**: в localStorage браузера (base64)

### Рекомендации:
- Оптимизируйте изображения перед загрузкой (сжатие, ресайз)
- Используйте формат WEBP для лучшего соотношения качества/размера
- Для больших изображений используйте внешние хостинги (Imgur, Cloudinary)

## 💾 Хранение данных

Все данные сохраняются в **localStorage** браузера. Это означает:
- ✅ Данные сохраняются между сессиями
- ✅ Работает без серверной части
- ✅ Загруженные изображения хранятся в base64
- ⚠️ Данные привязаны к браузеру
- ⚠️ При очистке браузера данные удалятся
- ⚠️ Ограничение localStorage ~5-10 МБ

### Сброс данных
Для сброса всех данных к начальным значениям:
```javascript
localStorage.clear();
location.reload();
```

## 🎯 Примеры использования

### Добавление нового продукта
1. Перейдите в раздел **"Продукция"**
2. Нажмите **"Добавить продукт"**
3. Заполните форму:
   - Название
   - Описание
   - Цена
   - Рейтинг
   - **Загрузите изображение** (перетащите или выберите файл)
   - Или выберите из галереи
   - Добавьте особенности
4. Нажмите **"Сохранить"**

### Загрузка изображения
1. В форме редактирования найдите поле "Изображение"
2. **Перетащите файл** в зону загрузки или **нажмите** на неё
3. Выберите файл с компьютера (PNG, JPG, WEBP до 2 МБ)
4. Изображение автоматически сохранится в галерею
5. Можно удалить изображение из галереи (крестик при наведении)

### Обработка заявки
1. Перейдите в раздел **"Заявки"**
2. Найдите нужную заявку в таблице
3. Нажмите на иконку **"Глаз"** для просмотра деталей
4. Измените статус через выпадающий список
5. Статус автоматически сохранится

### Изменение контактов
1. Перейдите в раздел **"Настройки"**
2. Выберите вкладку **"Контакты"**
3. Измените нужные поля
4. Нажмите **"Сохранить изменения"**

## 🐛 Устранение неполадок

### Данные не сохраняются
- Проверьте, не отключён ли localStorage в браузере
- Очистите кэш и попробуйте снова
- Проверьте консоль браузера на ошибки

### Админка не открывается
- Убедитесь, что URL содержит `#admin`
- Попробуйте обновить страницу
- Проверьте консоль браузера на ошибки

### Изображения не загружаются
- Проверьте формат файла (должен быть PNG, JPG, WEBP или GIF)
- Убедитесь, что размер файла не превышает 2 МБ
- Проверьте, не заполнен ли localStorage (лимит ~5-10 МБ)
- Попробуйте сжать изображение перед загрузкой
- Очистите старые загруженные изображения из галереи

### localStorage переполнен
- Удалите ненужные загруженные изображения из галереи
- Очистите старые проекты или продукты
- Используйте внешние хостинги для больших изображений

## 📞 Поддержка

При возникновении проблем:
1. Проверьте консоль браузера (F12)
2. Очистите localStorage
3. Обновите страницу
4. Обратитесь к разработчику
