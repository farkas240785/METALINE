# Административная панель METALINE

Полнофункциональная админ-панель для управления контентом сайта METALINE.

## 🚀 Доступ к админ-панели

### Способ 1: Через футер сайта
Прокрутите сайт до футера и нажмите на ссылку **"Админ-панель"** в нижней части.

### Способ 2: Прямой URL
Добавьте `#admin` к URL сайта:
```
https://your-domain.com/#admin
```

### Выход из админки
- Нажмите кнопку **"Выйти"** в боковой панели
- Или нажмите **"Открыть сайт"** для возврата на основной сайт

## 📊 Разделы админ-панели

### 1. Дашборд
Обзор ключевых показателей:
- Статистика заявок (новые, в работе, завершённые)
- График выручки по месяцам
- Статусы проектов
- Последние заявки
- Быстрые действия

### 2. Продукция
Управление каталогом продукции:
- Добавление/редактирование/удаление продуктов
- Изменение статуса (активен/скрыт)
- Загрузка изображений
- Управление ценами и рейтингами
- Поиск по названию

### 3. Портфолио
Управление проектами:
- Добавление новых проектов
- Редактирование существующих
- Фильтрация по статусу (опубликовано/черновик)
- Загрузка изображений
- Управление рейтингами

### 4. Заявки
Обработка входящих заявок:
- Просмотр всех заявок
- Фильтрация по статусу
- Изменение статуса заявки
- Просмотр деталей заявки
- Управление приоритетами

### 5. Техническая библиотека
Управление документами:
- Добавление новых документов
- Редактирование информации
- Удаление документов
- Отслеживание скачиваний
- Категоризация документов

### 6. Пользователи
Управление доступом:
- Просмотр списка пользователей
- Блокировка/активация пользователей
- Просмотр ролей и последнего входа

### 7. Настройки
Конфигурация сайта:
- **Общие**: название компании, режим обслуживания
- **Контакты**: телефоны, email, адрес, часы работы
- **Соцсети**: ссылки на социальные сети
- **SEO**: мета-теги для поисковых систем

## 💾 Хранение данных

Все данные сохраняются в **localStorage** браузера. Это означает:
- ✅ Данные сохраняются между сессиями
- ✅ Работает без серверной части
- ⚠️ Данные привязаны к браузеру
- ⚠️ При очистке браузера данные удалятся

### Сброс данных
Для сброса всех данных к начальным значениям:
```javascript
localStorage.clear();
location.reload();
```

## 🔐 Безопасность

**Важно**: Это демонстрационная админ-панель без реальной аутентификации.

Для production-версии необходимо:
1. Добавить реальную аутентификацию
2. Использовать серверное хранилище (база данных)
3. Реализовать систему ролей и прав доступа
4. Добавить логирование действий
5. Настроить CORS и защиту от CSRF

## 🎯 Примеры использования

### Добавление нового продукта
1. Перейдите в раздел **"Продукция"**
2. Нажмите **"Добавить продукт"**
3. Заполните форму:
   - Название
   - Описание
   - Цена
   - Рейтинг
   - Выберите изображение
   - Добавьте особенности
4. Нажмите **"Сохранить"**

### Обработка заявки
1. Перейдите в раздел **"Заявки"**
2. Найдите нужную заявку в таблице
3. Нажмите на иконку **"Глаз"** для просмотра деталей
4. Измените статус через выпадающий список
5. Статус автоматически сохранится

### Изменение контактов
1. Перейдите в раздел **"Настройки"**
2. Выберите вкладку **"Контакты"**
3. Измените нужные поля
4. Нажмите **"Сохранить изменения"**

## 🐛 Устранение неполадок

### Данные не сохраняются
- Проверьте, не отключён ли localStorage в браузере
- Очистите кэш и попробуйте снова
- Проверьте консоль браузера на ошибки

### Админка не открывается
- Убедитесь, что URL содержит `#admin`
- Попробуйте обновить страницу
- Проверьте консоль браузера на ошибки

### Изображения не загружаются
- Проверьте интернет-соединение
- Убедитесь, что URL изображений доступен
- Попробуйте выбрать другое изображение

## 📞 Поддержка

При возникновении проблем:
1. Проверьте консоль браузера (F12)
2. Очистите localStorage
3. Обновите страницу
4. Обратитесь к разработчику
