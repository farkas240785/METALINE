# METALINE — Фабрика перегородок из алюминиевого профиля

Современный корпоративный сайт для фабрики METALINE с премиальным дизайном и полнофункциональной админ-панелью.

## 🚀 Быстрый старт

### Восстановление сайта из репозитория

**Linux / macOS:**
```bash
chmod +x restore.sh
./restore.sh
```

**Windows:**
```cmd
restore.bat
```

### Ручная установка

```bash
npm install
npm run build
npm run dev
```

| Раздел | Описание |

## 🔐 Административная панель

Для управления контентом сайта предусмотрена полнофункциональная админ-панель.

### Доступ к админке:
1. **Через футер сайта** — нажмите ссылку "Админ-панель" в нижней части сайта
2. **Прямой URL** — добавьте `#admin` к адресу сайта: `yoursite.com/#admin`

### Возможности админки:
- 📊 **Дашборд** — статистика, графики, последние заявки
- 📦 **Продукция** — управление каталогом (CRUD)
- 🖼️ **Портфолио** — управление проектами
- 📨 **Заявки** — обработка входящих заявок с фильтрами
- 📚 **Библиотека** — управление документами
- 👥 **Пользователи** — управление доступом
- ⚙️ **Настройки** — контакты, соцсети, SEO

Подробная документация: [src/admin/README.md](./src/admin/README.md)
